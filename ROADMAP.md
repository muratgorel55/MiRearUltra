# 🗺️ MiRearUltra Project Roadmap

MiRearUltra is currently in **v1.1 Alpha (Public Preview)**. Below is the development path and planned milestones.

---

## 📍 Phase 1: Alpha (Current - v1.1)
- [x] Native 120Hz LTPO canvas rendering engine on secondary display (`Display #1`).
- [x] Shizuku multi-display virtual presentation and touch injection bridge.
- [x] Top 10 world languages localization (EN, ZH, ES, HI, AR, BN, PT, RU, JA, TR).
- [x] Fast 6-contact Speed Dial with custom contact picker and phone dialer.
- [x] Privacy call management (auto-clear overlay on call answered).
- [x] Fluid pull-down notification curtain with auto-scroll.
- [x] Pocket and face-down proximity protection.
- [x] Quick Tools (Torch, Voice Memo) and Retro Mini Brick Game.

---

## 📍 Phase 2: Beta (v1.5)
- [ ] **Rear Camera Viewfinder:** Real-time camera mirror preview for high-res selfies using primary rear sensors.
- [ ] **Dynamic Live Activities:** Media playback pill, timer countdowns, and ride-sharing updates.
- [ ] **Always-On Display (AOD) Modes:** Ultra-low frequency 1Hz refresh mode for minimal battery impact.
- [ ] **Custom Theme & Wallpaper Store:** Import animated GIFs, custom video loops, and SVG clock hands.
- [ ] **Biometric Rear Unlock:** Experimental rear display pattern / tap code unlock.

---

## 📍 Phase 3: Stable (v2.0)
- [ ] Direct HyperOS system plugin support (Magisk / KernelSU / APatch module variant).
- [ ] Independent app launcher on rear screen for selected lightweight Android apps.
- [ ] Comprehensive unit and instrumentation test suite.
- [ ] One-click OTA updates via GitHub Releases.
